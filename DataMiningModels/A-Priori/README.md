# A-Priori Algorithm – Association Rule Mining

This project implements the **A-Priori algorithm** for association rule learning, a popular data mining technique used to find frequent itemsets and derive rules such as *"if item A is bought, item B is likely to be bought too."*  

It uses a sample grocery dataset to generate frequent itemsets and association rules.

---

## 📂 Project Structure

- **`groceries2.csv`** – Dataset of grocery transactions  
- **`script.py`** – Main Python script implementing the A-Priori algorithm  
- **`FItems.txt`** – Output file containing frequent itemsets  
- **`Rules.txt`** – Output file containing generated association rules  

---

## 🚀 Features

- Implementation of **A-Priori algorithm** for frequent itemset mining  
- Generation of **association rules** with support and confidence thresholds  
- Works on transaction-based datasets (e.g., shopping baskets)  
- Saves results to text files for easy review
