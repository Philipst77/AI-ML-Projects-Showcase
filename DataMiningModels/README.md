# DataMiningModels

This repository is a collection of **machine learning and data mining models**, built for experimentation, practice, and demonstration of core concepts in applied AI/ML.  
Each folder represents a **self-contained project** with its own implementation, datasets (if applicable), and Jupyter notebooks.

---

## 📂 Repository Structure

The repo includes a wide variety of classic and modern ML models/techniques:

- **A-Priori** – Association rule learning for market basket analysis  
- **Anomaly_detection** – Detecting outliers and rare events  
- **ArtificialNeuralNetwork** – Feedforward neural network implementations  
- **AutoEncoder** – Dimensionality reduction and representation learning  
- **Bias_Variance_Trade_Off_AND_OLS_WLS** – Regression models and bias-variance tradeoff exploration  
- **Classification_imbalanced_datasets** – Handling imbalanced datasets in classification problems  
- **DataExploration** – Exploratory data analysis utilities  
- **DecisionTrees** – Implementation of decision tree models  
- **Hierarchical_Clustering** – Agglomerative clustering and dendrograms  
- **K-NN with CrossValidation** – K-Nearest Neighbors with validation strategies  
- **KernelKmeans** – Nonlinear clustering with kernelized k-means  
- **L2_Dropout_EarlyStop_NN** – Neural networks with regularization techniques  
- **LDA** – Linear Discriminant Analysis for classification  
- **LinearRegressionI_LinearRegressionII** – Linear regression with L1/L2 regularization  
- **SVDImplementation** – Singular Value Decomposition for dimensionality reduction  
- **SVM** – Support Vector Machine implementations  

---

## 🚀 Features

- Covers **supervised, unsupervised, and semi-supervised** learning  
- Hands-on **Jupyter notebooks** for interactive exploration  
- Implementations focus on **clarity and educational value**  
- Includes both **traditional ML** and **deep learning** models  
- Provides code for **regularization, model evaluation, and cross-validation**
